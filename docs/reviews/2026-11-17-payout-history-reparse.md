# 過去の払戻表の読み直し（2026-11-17）

10/14 の監査で残っていた不備（D2: 過去の払戻表は拡連複が 1 行だけ・単勝と複勝が無い、D5: 2004〜2005年の「返還」16%）を、手元の K ファイル（公式の結果アーカイブ）を読み直して直した記録。外へのアクセスは無い。夜間（00:50〜01:10）に実行した。

## 結論

- **過去の払戻表（`race_payouts`）は、2000年・2004年〜2026年の全期間で全 7 券種がそろった。** 6,137,623 行 → 11,812,466 行。既存の行の金額・人気は 1 件も変わっていない（下の「誤って付いていた 6 レース」を除く）。
- **「返還 16%」の正体は特払いだった。** 古い読み方は、単勝・複勝などの特払い（的中票が無いときの 70 円の払戻）をレース全体の返還にしていた。今の読み方では返還にしない。返還の印が付いた払戻の行は 290,910 → 1,592、レース（`race_conditions`）は 62,087 → 3,639。
- **K ファイルの読み落としを 5 種類見つけて直した**（下の表と、最後の章）。読み直しの前に、全 8,317 ファイルを書き込みなしで DB と照合した。
- **BUY の当たり外れの数え方の穴も、同じ日に直した**（最後から 2 つ目の章）。paper-live の BUY 2 件が、本当は返還なのに「はずれ」になっていた。
- 拡連複の 1番人気を買い続けたときの回収率は 71.4%（2010〜2025年・863,771 レース・的中 53.4%）。6月の「0.379」は欠損による数字で、ほかの券種（74.6〜75.9%）と同じ水準だった。**edge が無い結論（K1）は変わらない。**

## BUY の当たり外れの数え方（同じ日の昼に直した）

読み直しの途中で、**BUY の当たり外れの数え方に穴**があると分かった。結果表（`race_results`）の 1 行だけで決めていたのが原因。

**訂正: この文書の最初の版は「今までの成績への影響は 0 件」と書いたが、誤りだった。** 「返還」の印が付いたレースの BUY だけを調べ、印が付いていないレースを見ていなかった。BUY を 1 件ずつ新旧の決め方で比べると、paper-live で 2 件が違った。

| 何が起きていたか | 例 | paper-live の BUY への影響 |
|---|---|---|
| 買い目の艇がフライングでも、ほかの券種が全部成立していれば印が付かず、「はずれ」と数えた（本当は返還） | 10/22 鳴門 7R（1・2 号艇が F）、11/5 丸亀 4R（1 号艇が F）。買い目はどちらも 1-2-3 | **2 件**。「❌ はずれ」と通知していた。公式の結果ページの「返還」の欄でも確かめた |
| ほかの券種の特払い・不成立で印が付くと、3連単がふつうに確定していても「返還」と数えた | 2024-01-07 津 8R（全艇完走・結果 6-3-5） | 0 件（過去の再生で 5 件） |
| 同着の 2 つ目の当たりを「はずれ」と数えた | 2025-01-04 津 2R の 1-2-4 | 0 件（同着で 3連単が 2 つあるレースは全期間で 530、2026年は 15） |
| 3連単が成立しなかったレースは、結果表に行が無く、いつまでも「結果待ち」 | 2026-10-08 鳴門 5R | 0 件（過去の再生で 5 件） |

直したこと（6d216f37）:

- 決め方を 1 か所にまとめた（`src/domain/buySettlement.ts` の `settleTrifectaBuy`）。買い目にフライング・出遅れ・欠場の艇があれば返還、3連単が成立しなければ返還、払戻の行（同着なら 2 つ）に買い目があれば的中、無ければ外れ、確定結果が無ければ結果待ち。
- 通知（速報・確定・日次まとめ）・財布・スコアカード・成長レポート・本命予想の参考集計が、同じ決め方を使う。BUY の判定は変えていない（財布の代も変えない）。
- 速報は、公式の結果ページの「返還」の欄の艇も読む。速報と確定で結論が違えば、確定通知で知らせ直す。
- 欠場と、進入の無い出遅れの艇は、K ファイルの行の形が違って `race_entries` に入らない。2010年以降で読めない行 8,602 のうち 8,601 がこの 2 つなので、1〜6 号艇のうち行の無い艇も返還の艇として扱う。

本番の DB で、直す前と後を比べた（読み取りだけ）:

| | 前 | 後 |
|---|---|---|
| paper-live の BUY 243 件 | 5 勝 237 敗・返還 1 | 5 勝 235 敗・返還 3 |
| 2代目の財布（10/10〜） | 5,600 円 | 5,800 円 |
| 初代の財布（7/20〜10/9） | 6,800 円 | 6,800 円（変わらず） |
| スコアカードの注意「3日以上前の BUY の結果が未取り込み」 | 毎日 1 件 | 出ない（返還の BUY を結果待ちに数えた誤りだった） |
| 本命予想の参考集計（7/1〜11/15） | 1,195 勝 11,216 敗・回収率 72% | 1,196 勝 11,118 敗・回収率 73%（返還を外れに数えていた 98 件が外れた） |

直した 2 件の「はずれ」の通知は、送り直していない（送信済みの通知は作り直さない決まり）。財布とまとめの数字は、反映した日の夜から正しくなる。

## 読み落としの 5 つ目（同じ日の昼に直した）

場ごとの先頭にある払戻の一覧（`[払戻金]` の表）の「不成立」を、前の場の最後のレース（12R）の返還の印として拾っていた（2026-10-08 児島 12R: 全艇完走なのに印が付いた）。直すと、`race_conditions` の返還の印は 3,639 → 1,904 レース。払戻の行は変わらない（b8d705be）。過去分は夜間の読み直しで直す。この印を読んでいる処理は無い。

`race_results.returned`（結果表の印）は、古い読み方のまま残している。成績の計算はもう使わない（各艇の成績が無いレースの予備としてだけ読む）。
