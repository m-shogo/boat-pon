## 3. データの事実（どれを信じてよいか）

- **信じてよい**: 3連単の結果と払戻（`race_results`）。全券種の払戻表と照合できた 5,285 レースで食い違い 0。各艇の着順とも 5,274 レース中 1件（3着が空）を除き一致。
- **欠けがある**: 番組表（2025-11-21〜2026-05-19）、結果（2026-05-21〜25・6/2〜6/9 の一部、K ファイルが無い日 27日）、全券種の払戻表（2026-06-02〜10-06。毎日の取り込みは 2026-10-08 から）。
- **不完全**: 過去の全券種の払戻表（2004〜2026-06-01）は拡連複が1レース1行、単勝・複勝が無い。拡連複・単勝・複勝の分析には使わない。
- **意味が違う**: 2004〜2005年の「返還」16% は、3連単が未発売だった場を返還と数えている可能性が高い。分析は 2010年以降を使う。
- **リークする**: `racer_profiles`・`racer_course_stats` は live のスナップショット。過去のレースに使わない。番組表の raw_json の値は過去にも安全。
- **使い方の注意**: `decision_history` は `run_kind`・`model_version` で分け、(race_id, bet_type, selection) ごとに最新の1行に絞って数える。`decision_history.popularity` は実際に勝った3連単の人気で、自分の買い目の人気ではない。
- 監査の再実行: `npm run audit:data-integrity`。詳細は [data-audit](reviews/2026-10-14-data-audit.md)。

## 4. 手法の罠

1. ROI は公式払戻で出す。表示オッズ（current_odds）・T-5 オッズの EV は楽観的（K4）。
2. in-sample → 外部検証 → held-out → forward の順を飛ばさない。同じ外部データで何度も検定しない。
3. 判定の条件（閾値・会場・時間帯）を細かく分けるほど、見かけの ROI は上がる。分けた数だけ、偶然の当たりを拾う。
4. 信号は「行動できた時点」で評価する。締切後に付いたラベルや、後から届いた情報で作った判定は、成績に入れない（K5）。
5. 精度は「同じレース」で比べる。期間ごとの logloss の値そのものは、含まれるレースで上下する（成長レポートは差で比べる）。
6. 分布と価格を分けて見る。「よく当たる」と「儲かる」は別の問い（K3・R5）。

## 5. 運用の教訓

1. **決定的な実験を先に回す。** 2026-07-26 には判定に必要なサンプルがそろっていたのに、8〜9月の研究基盤のコミットは 2,124件（成長レポートの集計）で、判定は 10/7 まで回らなかった。基盤の作業は「次の決定的実験に必要か」で選ぶ。
2. **「success」は中身で見る。** 取得件数・精算件数・最終日付で監視する。終了コードだけを見ない（private capture は認可切れで 0件のまま success を出し続けた）。
3. **一度きりのバックフィルは、毎日の取り込みにも入れる。** 全券種の払戻は 6/5 に一度入れたきりで、122日空いた。
4. **記録は行動の締め切りで固定する。** 締切後の再評価で上書きしない（2026-10-09〜）。判定の時刻は「判定の段階の時刻」を使う（実行開始時刻を使って 26行がすり抜けた。2026-10-14 に修正）。
5. **静かに落とさない。** 条件で通知しなかった BUY も、理由をログに出す（`LINE realtime not-sent:`）。
6. **結論は repo に書く。** 2026-06-05 の「利益化不可能」は memory にしか無く、研究工場からは見えなかった。この文書がその置き場所。
7. **毎回「全期間」を読む処理は、データが増えるほど遅くなる。** auto-odds は判定の前に全期間のオッズ（約230万行）を毎回読み、約40秒かかっていた。遅さは少しずつ増えるので気づきにくい。ライブ経路は、その日のデータだけを読む（2026-10-14 に修正。判定は 12 通りの比較で一致）。
8. **知識の量は「教訓の数」で測れる。** lessons-learned の項目は 5月 23件 → 6〜9月 0件 → 10月 3件。8〜9月はコミットが最も多かったが、人が読める知識は増えていなかった（研究工場の学びは `research/registries/learnings/` の機械向け JSON 11件だけ）。
