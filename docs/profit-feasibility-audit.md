# 利益可能性の根本監査

## 結論

2026-07-18時点で、boat-ponに**再現確認済みの利益優位性はない**。これは「永久に儲けられない」という証明ではないが、現行モデルの閾値調整やBUY数増加では解決しない。

```bash
pnpm audit:profit-feasibility
pnpm audit:t5-market-coverage -- --strict
pnpm audit:candidate-selection -- --strict
```

この監査はDB読み取り専用で、app_settings・本番decision・通知・投票には接続しない。

## 根底から否定された前提

1. **高いモデルEVほど有利**: 2024年から2025年にかけてEV閾値を上げるほどROIが悪化した。
2. **市場にモデルを少し混ぜれば改善する**: T-5全120通りの結果確定272レースでは、モデル10%混合から的中0だった。
3. **過去にROI 100%を超えた条件はedge候補**: 後から選んだ条件は未使用期間で反転している。
4. **closing oddsで良ければ実運用できる**: closing oddsは締切前に確実に利用できず、T-5の購入可能価格ではない。
5. **保存済みexactaデータは市場全体**: 完全30通りがあるのは2024年2,762レース、2025年1,492レースだけで、公式番組全体の一部にすぎない。

## 2024→2025固定戦略の再現性

- closing odds最人気: 2024 ROI 77.76% → 2025 ROI 74.58%
- 2024年に最良だった固定買い目 `2-1`: ROI 89.1% → 2025 ROI 53.5%
- 2024年の全固定買い目に損益分岐超えはなく、訓練期間の首位すらforwardで悪化した
- 2025年の最良買い目を後から選ぶ行為はpost-hocであり、edgeの証拠に数えない

市場最人気の2025 ROI 74.58%を基準にすると、損益分岐には約34%の相対改善が必要になる。小さな精度改善では足りない。

## まだ利益を狙うなら変えるもの

予測器の微調整ではなく、実験設備を作り直す。

1. 全レース・全120通りのT-5オッズを欠損なく保存する。
2. 結果を見る前に仮説・特徴量・期間・採否条件を固定する。
3. 市場確率そのものではなく、市場確率に対する残差だけを学習する。
4. 月単位の完全なfuture-only期間で、市場baseline、公式払戻ROI、CLV、最大2hit除外ROI、最大DDを同時評価する。
5. 最低1,000 settledレースまではモデルを選ばず、同じholdoutを繰り返し見ない。
6. それでも損益分岐を超えなければ、競艇の自動予測を利益事業としては撤退する。

BUYを増やすことは目標にしない。検証されたedgeが出た場合にだけBUYが生まれる構造にする。

## 現在の研究停止ゲート

2026-06-01〜2026-07-17の公式番組6,999レースに対し、T-5全120通りが揃ったのは349レース（4.99%）、結果確定済みは277レースだった。必要条件のcoverage 80%、settled 1,000件に未達のため、市場残差モデルの選択・採用は停止する。

候補整合性は2026-07-18の修正前に買い目別オッズ不一致6,510/6,695行、保存top1一致5/64（7.8%）だった。買い目別オッズ優先と1レース1top1保存へ修正後、read-only再計算上のオッズ不一致は0件。過去の誤保存行は書き換えず、今後分がstrict監査を通るまで研究結果を昇格させない。

## 2026-10-07 最終判定: 撤退条件（上の6項）を満たした

研究停止ゲート（coverage・settled 1,000件）は、2026-07-26 の時点でサンプル数として到達していた。上の手順2〜5のとおり、事前登録した条件で forward 評価を行った。

- 事前登録の T-5 市場残差（6月で学習・パラメータ固定、forward は 2026-07-01〜10-07 の 9,417 レース）: forward logloss は残差 4.0054、市場 3.8014。**全月で市場に負けた。** 月次 walk-forward で再学習しても 3.8400 で負け。EV ベットの ROI は公式払戻で 55〜77%。
- Late money（T-10→T-5 の確率変化。2026-10-07 に事前登録）: logloss は 3.7682 で市場の 3.7838 をわずかに上回るが、EV ベットは ROI 51.9%。**REJECT。**
- 的中した買い目の確定払戻は、T-5 オッズの平均 95.2%。最も有利なオッズ帯（1〜10倍）でも確定払戻の ROI は約75%。
- paper-live BUY（2026-07-20〜10-07）: 175件を精算して3的中、実払戻 ROI 63.4%。ただし締切前に通知できたのは 32件で 0的中。残りは締切後の再評価で付いた BUY のラベルで、行動できた記録ではない（2026-10-08 の追加調査）。

- 2026-06-05 にも「公開情報では利益化不可能、残る未踏は sharp money のみ」という結論が出ていた（当時は repo に記録されていなかった）。今回の late money 検証で、その最後の候補も閉じた。

**結論: 公開情報で3連単を自動予測して利益を出す、という方向からは撤退する。** 詳細・再現手順・この判定の限界は [`docs/reviews/2026-10-07-strict-review.md`](reviews/2026-10-07-strict-review.md) にまとめた。
