# 取得不能な日付の記録

最終更新: 2026-05-23

公式 (mbrace.or.jp) に LZH 自体が存在しない、または常時 404 を返す日付の記録。
何度リトライしても取得できないため、Boat Pon ではこれらの日付は永久にデータ欠損として扱う。

## サマリ

| 種別 | 件数 | 期間 |
|---|---|---|
| K (競走成績) | **20日** | 2004-08-30 と 2011-03-13〜31 |
| B (番組表) | **17日** | 2011-03-15〜31 |

## 詳細と推定原因

### A. 東日本大震災による全国開催中止 (2011-03-13〜31)

| 日付 | K未取得 | B未取得 | 推定原因 |
|---|---|---|---|
| 2011-03-12 | ❌ なし | ✅ あり | 震災翌日。 番組表は事前発表済 |
| 2011-03-13〜14 | ✅ なし | ✅ あり | 番組表のみ事前発表されたが、 開催は中止で結果記録なし |
| 2011-03-15〜31 | ✅ なし | ✅ なし | 全競艇場で開催中止。 公式の番組表LZH・成績LZH 配信なし |

**事実関係（推定）:**
- 2011年3月11日 (金) 14:46 東日本大震災発生
- BOAT RACE 振興会 (旧 全国モーターボート競走会連合会) は当日のレースを中止
- 翌日以降、 全国24会場で開催を停止 (一部は数日後に再開、 関東圏は長期停止)
- 開催が無い日は公式の競走成績ファイル (K) も番組表ファイル (B) も生成されないため、 mbrace.or.jp の od2/{K,B}/YYYYMM/ 配下に LZH が存在しない (404)

**裏取り余地:**
- 公式アーカイブで震災後の開催状況を確認 (boatrace.jp/owpc/pc/extra/data/download.html の周辺)
- 各競艇場の年史・公式リリースで停止期間の正確な日付確認

### B. 2004-08-30 (K のみ、 月曜)

| 推定原因 |
|---|
| 月曜日定休 (一部の競艇場は月曜休) で全国的に開催無し |
| または公式の電子データ配信が安定する以前 (古い時代のフォーマット試行錯誤期) で欠落 |

**裏取り余地:**
- 2004-08-30 前後 (2004-08-29 日, 2004-08-31 火) は取得済 → 月曜定休説が有力
- 公式の最古配信日が 2004-06-01 (Boat Pon の取得開始日と同じ) であることも合わせて確認したい

## 取り扱い方針

- `data/boat.sqlite` には欠損として記録なし
- バックテストの集計では「欠損日 = 開催無し」 として除外扱い (件数集計に影響しない)
- 期間カバー率の算出時は分子分母から除外しない (= 統計的に 99.5% 取得済)
- 取り直すことはしない (`fetch-pending-*.txt` 再生成で常に同じリストが出る)

## 取得スクリプト側の挙動

`scripts/fetch-pending-parallel.ts` 実行時、 これら 37日は HTTP 404 を即座に受け取り `notFound` カウントに加算してスキップする。 ローカルにキャッシュも作らない (空ファイル化しない)。
