# 予測改善ロードマップ

更新: 2026-07-23

この計画は、BUY通知を増やすためではなく、予測確率が市場と実払戻を上回るかを段階的に検証するためのもの。全段階でDB書き込み・本番判定変更・自動投票は行わない。

N0後の全体順序と評価分離は[`research-platform-master-plan.md`](research-platform-master-plan.md)、市場残差モデルの詳細は[`market-residual-ticket-selection-roadmap.md`](market-residual-ticket-selection-roadmap.md)を正本とする。Phase N0は完了したが、次はモデルでもN1でもなくStage F0である。現時点のモデル側作業は`legacy_t5_formal`のformal settled固定条件蓄積であり、N0/F0完了を市場残差モデル開始理由にしない。

現行benchmarkと新研究を同一評価系列へ混ぜない。Legacy formal ROI、market-only baseline ROI、new shadow ROI、券種別shadow ROI、各方式のselected-race ROI、common-cohort比較ROIを別々に算出する。新方式は`market_intelligence / shadow_forward`でN7・N8までshadow専用とし、Decision GovernorはN7以降の別設計とする。

## 現在地

- 現行 `boatpon-v3-alpha15` は、3連単BUY 6,205件で平均推定4.01%に対し実績1.97%。確率を約2倍に見積もっている。
- 実払戻ROIは69.32%。current_oddsだけで見ると楽観的になる。
- train較正係数は0.474、forwardは0.519。月別係数は0.156〜0.755、会場LOOでも安定しない。
- 既存BUYへ較正係数を適用すると、現行EV閾値を通過する候補は0件。単純な係数変更は採用しない。
- モデル候補を経由しない純粋なT-5全120通り市場ベースラインは、結果確定317レースで実払戻ROI72.08%（最大2的中除外63.59%）。現行モデル混合は市場のみを上回っていない。
- 旧market-only集計はモデル生成済み買い目集合を経由していたため正式基準から除外し、`audit:t5-market-baseline`を基準器に固定した。
- 完全市場の定義を「同一checkpoint内のunion」から「単一captured_atで120通り」へ厳格化。317件の確定母集団と主要指標が不変であることを再確認した。
- ただし収集器の5分キャッシュが前checkpointのHTMLを現在checkpointとして保存し得たため、修正前317件は時点鮮度を完全証明できない参考値へ降格。2026-07-21 15:15 JST以降のnetwork-only future cohortを正式母集団にする。

## 改善の順序

### Phase 0: 評価契約を固定（完了）

同じ `race_id` 母集団、bet_type、run_kind、時点を明示し、`payout_yen`を主ROIにする。

合格条件:

- historical / forward / paper-liveを混ぜない
- returned・未確定・払戻欠損を別状態にする
- current_oddsを実払戻の代替にしない

### Phase 1: 確率較正の安定性確認（実施中）

月別、会場LOO、最大払戻除外で、補正が同じ方向に出るかを見る。現在は不合格。

合格条件:

- trainとforwardの較正係数差が±0.15以内
- n≥30の月で係数の極端な崩壊がない
- 最大払戻1〜2件除外後も方向が維持される
- 会場LOOで特定会場だけに依存しない

不合格なら、確率係数を本番へ入れず、特徴量追加も止める。

### Phase 2: 市場ベースラインを正式化（実施中）

モデル確率ではなく、T-5時点の全120通りオッズを正規化した市場確率を基準にする。

比較対象:

1. 市場確率のみ
2. 現行モデルのみ
3. 市場確率に対する残差モデル

残差は `実着順 - T-5市場確率` とし、単純なモデル確率blendは禁止する。

現在の進捗:

- T-5あり491レース
- 全120通り・結果確定317レース
- discovery 203レース: ROI78.57%
- forward 114レース: ROI60.53%
- 収集器の根本修正を実施: 締切順処理、時刻再計算、同一checkpoint重複回避、08時台対応、欠場市場と通信欠損の分離
- T-5収集を締切1分前まで、BUY通知を5分以上前に分離。旧時系列48,896,342行の42.62倍重複を特定し、新規重複率は約1.1倍まで抑制
- 修正前を含む累積coverageではなく、2026-07-21以降の日次80% gateで収集品質を判定する
- 修正後cohortは21/21でT-5完全取得、T-10あり/T-5欠測0。当日締切済み全体は52/71（73.24%）で、完成日80% gateは未通過
- network-only正式cohortは別集計を開始。最初のfresh T-5取得3件は監査時点で締切前のため、結果・coverage母数にはまだ入れない
- ユーザー報告の2026-07-23 13:12 JST時点はnetwork-only完全市場231/275（84.00%）。今回16:30 JSTのforward再監査では収集の自然増加により281/325（86.46%）となったが、結果確定は52/1,000のまま。市場ROI64.23%、最大1的中除外40.98%、最大2的中除外29.60%で全昇格gateはBLOCKED
- 最低1,000レースgateは未達

合格条件:

- network-only化後にT-5全120通りが揃ったレース1,000件以上
- 市場のみを同一期間・同一レース集合で比較
- forward実払戻ROI ≥100%
- 最大2的中除外ROI ≥100%
- CLVが正、最大ドローダウンを記録

### Phase 3: 残差モデルの最小構成

最初から選手・天候を大量投入しない。以下だけを事前固定して比較する。

- 市場確率、人気順位、オッズ帯
- 1号艇mass、2着・3着の市場確率
- 会場×艇番の残差
- 直前情報はT-5以前に取得できるものだけ

時系列splitを固定し、探索期間の結果をholdoutへ戻さない。モデル候補は1つずつpaper-forwardへ送る。

2026-07-21時点の実施結果:

- 6月train 203レース、7月forward 114レースで完全分離
- 市場temperature補正はforward loglossを3.7881→3.7767、Brierを0.9561→0.9553へ小幅改善したが、選択買い目が変わらずROI60.53%のまま
- 買い目別残差はtrain ROI145.67%に対しforward ROI72.81%。forward logloss4.1547、Brier0.9688へ悪化し、明確な過学習
- 全昇格gate不通過。買い目別残差モデルは終了し、本番・BUY通知へ接続しない

2026-07-23の追加検証:

- 2023-2024だけで番組能力・モーター/ボート・展示を学習し、2025/2026を固定forward評価した
- 2026 testはROI83.92%、最大2的中除外78.59%、logloss 4.3727、Brier 0.9826で不合格
- 修正前T-5 197レースを係数校正専用にして市場との幾何混合を比較したが、logloss最小はα=0（市場だけ）
- formal同一50レースでも履歴単独はROI75.20%、市場は66.80%。履歴単独のlogloss/Brierは市場より悪く、本番へ接続しない

### Phase 4: 券種別のfuture-only検証

2連単・2連複を検証する場合は、券種を主キーに含む保存、T-5収集、払戻結合を順に完成させる。closing oddsとT-5を混ぜない。

合格条件:

- exacta/quinellaの30通りがbet_type付きで完全保存
- T-5時点で最低1,000レース
- 3連単と同じ母集団で比較
- 実払戻ROI・最大2件除外ROI・CLVが全て報告可能

### Phase 5: paper-forwardから本番候補へ

本番変更は最後。最低でも以下を満たすまでBUY通知・app_settingsへ接続しない。

- 未使用期間のforward n≥300（目標1,000）
- 的中数≥10
- 最大2件除外ROI≥100%
- 直近3か月に0%崩壊なし
- 会場LOO・月別・市場のみbaselineに対して再現
- 払戻欠損・返還・時点不整合ゼロ

## 失敗時の分岐

| 結果 | 対応 |
|---|---|
| 市場のみが最良 | モデルBUYを停止し、通知は監視専用にする |
| 残差がtrainだけ有効 | 過学習として不採用 |
| 特定会場だけ有効 | 会場固有モデルではなく紙検証継続 |
| 券種を変えてもROI<100% | 券種追加を停止し、予測対象を見直す |
| T-5データ不足 | 蓄積待ちを「検証済み」と表現しない |

## 現時点の判断

現行モデルの確率を補正してBUYを増やす段階ではない。formal蓄積と並行する新研究側は、まずF0で当時世界の再現・漏洩拒否を成立させ、N1〜N4の事実・観測基盤を経てN5の市場baselineへ進む。市場を上回る残差が確認できなければ、予測モデルの複雑化ではなく、見送り中心の運用を選ぶ。

現行システム全体の正誤・未完了項目は`reports/current-system-correctness-audit.md`を正本とする。収集や通知が正常でも、予測確率・実払戻ROIの不合格を打ち消さない。
