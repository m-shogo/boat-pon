## 5. BUY条件の候補フィルター

### 実績ベースの絞り込み（バックテスト内、過学習の可能性あり）

```
maxOddsRatio: 2.0  → 比率2.0超を除外（ROI: 0.471 → 0.671）
minOddsRatio: 1.5  → 比率1.5未満も除外（ROI: → 0.959 帯のみに絞り込み）
maxOdds: 50        → 50倍超を除外
```

- `maxOddsRatio=2.0` のみ: n=867, ROI 0.671
- `minOddsRatio=1.5 + maxOddsRatio=2.0`: n=286, ROI 0.959（最良帯、ただしn少）

⚠ **全てバックテスト内での最適化**。過学習の可能性が高く、実運用では慎重に検証が必要。

| 条件 | 理由 |
|------|------|
| EV 3.0以上 | n=253で全件ミス（`maxOddsRatio=2.4`相当） |
| オッズ50倍以上 | ROI < 0.2（損失大） |
