# ウォークフォワード期待値調整レポート

作成日: 2026-05-23 12:05:45
実行時間: 約60分
評価パス: 378

## 前提

- DBは `readOnly: true` で開き、`data/boat.sqlite` には書き込んでいない。
- 公式番組表を日付順に流し、各レース時点より前日の結果だけで会場別の最頻出3連単を推定した。
- オッズ履歴が十分でないため、今回は「実オッズが必要オッズを超えたか」は判定していない。
- その代わり、推定的中率と実測的中率のズレから targetEv を補正する方針で見る。
- ROIは「モデル候補を全て100円買った場合」の粗い参考値。実運用のBUY条件ではない。

## 結論

- 運用推奨 targetEv: **1.25維持**（下げない）
- 運用推奨 minSampleSize: **1000〜2500**
- 運用推奨 alpha: **1〜20**
- 理由: 直近期間 2025-01-01 以降で、推定的中率と実測的中率の比率(calibration)は 1.273 と悪くない。ただしオッズなしで最頻出3連単を全買いした粗ROIは 77.9% なので、targetEvを下げる根拠にはならない。**オッズフィルターが本体**で、的中率モデルは候補を絞るための前段と見る。

現時点では targetEv を下げる根拠は薄い。Boat Ponの思想どおり、**targetEv 1.25は最低ラインのまま維持**し、実測 calibration が低い期間では **1.35〜1.60 へ一段厳しくする**のが安全。

## 解釈メモ

- この検証は、未来データを見ない形で「会場別に強い買い目を選ぶ」だけの基礎モデルを評価したもの。
- 粗ROIが100%未満なので、**的中率だけで買うのは不可**。
- calibrationが1を超えているのは、推定的中率が実測より控えめに出ているという意味。ただし、それでも払戻込みの粗ROIは不足している。
- したがって期待値調整の結論は「targetEvを下げる」ではなく、**必要オッズ以上の時だけBUYにする条件をより重視する**こと。
- minSampleSizeは表上100でも同じ結果になっているが、これは直近2025年以降の各会場サンプルが既に十分大きいから。運用ではデータの薄い会場/条件を避けるため、1000〜2500を推奨する。

## 年代・ルール改定への対応方針

- 2004年から全期間を一枚岩で見ず、直近1年・3年・5年・全期間を分けて calibration を監視する。
- 直近だけ悪化する会場やレース番号は、すぐ除外せず WATCH 降格で様子を見る。
- ルール改定・展示/進入傾向・モーター制度・開催日程の変化が疑われる場合は、固定日付で切るよりローリング期間で変化点を探す。
- オッズ履歴が入った後は、年代別の「必要オッズを超えた時だけ」のROIを主指標にする。

## 推奨運用

1. **targetEvは1.25未満にしない。**
2. 直近3〜5年の calibration が 0.8 未満なら、実運用上の targetEv は `1.25 / calibration` で見る。
3. minSampleSize は、BUY候補が出すぎる間は **1000〜2500** に上げる。
4. alpha は 1〜20 の範囲でよい。0は過去頻度を信じすぎるので、データが薄い条件では避ける。
5. オッズ履歴が溜まるまでは、このレポートは「的中率校正」の材料であり、最終EVの確証ではない。
