# 番組・関係性・イベントの多因果検証

## 目的

公開情報から、オッズ市場が十分に織り込めていない番組構成・環境・選手文脈を探す。統計的な偏りを不正の証拠にはせず、個人を疑惑ランキングにしない。利益仮説と競技公正性の調査は、必要な証拠水準が異なるため分離する。

## 調べる因果経路

1. **公開番組設計**: 1号艇だけA級、1・4号艇だけA級、進入固定、企画レース、開催グレード。主催者が公開する構成効果であり、不正ではない。
2. **物理環境**: 風向・風速・波・潮位・気温と、会場形状・コース別得意の相互作用。
3. **選手の状態**: 展示、モーター、当地成績、短期移動、F後日数、前走内容。結果後にしか分からない情報を混ぜない。
4. **公開関係性**: 公式記事で確認した師弟、point-in-timeの支部・登録期、過去日までの同走・直接対戦。関係性そのものではなく、市場残差が追加で説明されるかを見る。
5. **注目・物語性**: 周年、誕生日、初優勝候補、地元開催、引退・復帰、冠イベント。まず売上やオッズ集中への作用と、着順への作用を分ける。
6. **市場構造**: 人気集中、控除率、締切直前の価格変化、買い目間の歪み。的中率向上と利益edgeを混同しない。

## 検証順序

1. レース前に取得できる定義・対象買い目・評価期間を固定する。
2. 正規化したT-5市場確率をbaselineにして、実着順との差だけを評価する。
3. 会場、月、開催、レース番号、級別構成、風、能力差を揃えた比較を行う。
4. 同一選手・同一会場内比較、leave-one-venue、leave-one-eventで特定集団依存を崩す。
5. 効果が出ないはずの買い目・風向・開催前期間をnegative controlにする。
6. 発見期間とforward期間を分け、最大配当除外、探索多重度、欠測率を併記する。
7. 将来データで再現するまでBUY・本番decisionへ接続しない。

## 「盛り上がり」仮説の分解

イベント時に売上が増えたり人気選手へ投票が集中したりするなら、最初に変わるのは結果ではなく価格である可能性が高い。したがって次を別々に測る。

- 売上・オッズ集中が変わるか。
- 市場確率を引いた後も着順残差が変わるか。
- 公開された企画編成を調整すると残差が消えるか。
- 誕生日・周年の前後で対称なevent studyになるか。
- 同じ選手の非イベント開催と比べても残るか。

価格だけが変わるなら「人気による割高・割安」の候補、着順だけが変わるなら状態・編成の未観測交絡を優先する。両方が変わっても、それだけで人為的操作とは判断しない。

## 公正性について言える範囲

異常値、師弟同走、地元選手、企画レース、締切前オッズ変動のいずれも単独では不正の証拠にならない。公正性の主張には、データ品質確認、事前固定した反復パターン、代替説明の排除、一次資料など追加の独立証拠が必要になる。本研究は収益仮説の集団集計までとし、個人への断定や公開告発には使わない。

## 現在の結論

- 過去同走・直接対戦の単純proxyは、南西風2〜3m・4号艇最強の1-4仮説を安定して説明しない。
- 公式出典付き師弟台帳は現時点で2組のみで、評価対象の1・4号艇pair該当は0件。効果は未検証。
- 公開企画番組に似た級別構成は、全天候では利益edgeがなく、南西風条件内だけ一部が強い。番組設計単独より環境との相互作用が候補。
- イベント11分類×exacta 5買い目の55セルでは、最大2的中除外ROIまで両期100%以上のセルは0。イベント単独のBUY根拠は見つかっていない。
- ルーキー開催の1-4は両期で市場残差がプラスだが、4号艇が他の外敵より全国勝率0.5以上高い条件まで絞ると2025 n=8。相対能力差の仮説として残すが小標本で採用しない。
- 開催初日・準優日・優勝戦日・開催後半・ドリーム・進入固定の50セルでも、最大2的中除外ROIが両期100%以上は0。開催終盤の盛り上がりを結果edgeとする仮説は不採用。
- 同日前走4着以下の4号艇を「反発期待」で買う仮説は両期で市場残差がマイナス。除外すれば1-4全体は改善するが黒字化せず、他の2着買い目へ逃がしても頑健なedgeはない。見送り材料としてのみ保留する。
- 直前までの外枠勝ち、4コース好調、荒配当、Fによる「今日の水面ムード」55セルでも頑健edgeは0。連続結果から次も同じとする物語は不採用。
- 当時の支部・年齢・身体情報を全対象で復元したが65セル中頑健edgeは0。同支部1-4のプラス残差は血液型一致placeboと同程度で、関係性の証拠として扱えない。
- exacta内の人気順位・1号艇票mass・市場集中・隣接買い目との相対価格55セルでも頑健edgeは0。整数オッズという無意味なplaceboのほうが派手なforward ROIを示し、市場形状の後付け物語も偽陽性対照なしでは採用できない。
- 他場締切との衝突・孤立・同日開催負荷55セルでも頑健edgeは0。孤立と混雑の双方で1-4残差がプラスに見えたが、会場×R番号×暦月を固定すると両期プラスを維持しない。唯一残る混雑1-6もleave-one会場で反転する。公式時刻表にも会場境界のparse誤認があるため、1〜12R完備・時刻単調増加を必須品質gateにした。
- 給与日前後・月初月末・五十日・曜日・賞与月proxyの55セルでも頑健利益は0。土日1-4は交絡調整後の残差差が残るが2024の外れ値除外ROI73.5%。無意味な日付placeboにも同程度の残差が出るため、売上・参加者数を観測せず資金流入の因果とは扱わない。
- 「事務所」に相当する公式データ構造は確認できていない。現時点では支部・登録期・公式師弟を別変数として扱う。
