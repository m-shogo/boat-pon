## 追記: 対応方針

- kyotei24のHTMLは、表示オッズと `display:none` の同値を同じセルに持つため、単純な `.text()` では `220.4220.4` のように連結される。
- パーサーは非表示要素を除外して表示値だけ読む方針に修正する。
- 100倍超オッズは、当面BUYではなくWATCH/検証保留に落とす。
- 既存の高オッズスナップショットは、rawキャッシュから `npm run repair:odds` で再パースして補正する。
