## 結論

### 実払戻でも有望な条件（payoutROI >= 100）
- なし（全条件で実払戻ROI < 100%）

### current_odds楽観だった条件（gap大 / currentOddsROI >= 100 だが payoutROI < 95）
- **A. 全体**: current_odds=100.79% → 実払戻=85.85% (乖離 14.94pt)
- **B. selection=1-2-3**: current_odds=100.12% → 実払戻=86.29% (乖離 13.83pt)
- **E. 1号艇展示タイム4位以下**: current_odds=105.74% → 実払戻=94.5% (乖離 11.24pt)

### gap >= 10pt の要注意条件
- **A. 全体**: gap=14.94pt (current=100.79% / payout=85.85%)
- **B. selection=1-2-3**: gap=13.83pt (current=100.12% / payout=86.29%)
- **C. 1号艇展示タイム1位**: gap=18.29pt (current=76.52% / payout=58.23%)
- **D. 1号艇展示タイム2〜3位**: gap=13.85pt (current=110.39% / payout=96.54%)
- **E. 1号艇展示タイム4位以下**: gap=11.24pt (current=105.74% / payout=94.5%)
- **K. 風速2〜4m/s**: gap=11.09pt (current=91.52% / payout=80.43%)
- **L. 風速2〜4 × 1号艇展示1位**: gap=13.92pt (current=51.05% / payout=37.13%)
- **M. 2号艇が3号艇より展示速い**: gap=12.58pt (current=111.51% / payout=98.93%)
- **N. 3号艇が2号艇より展示速い**: gap=17.28pt (current=96.54% / payout=79.26%)

### 今後の ROI 判断指針
1. **実払戻ベース（payout_yen）を基準にする** — current_odds ベースは参考程度
2. **乖離幅が大きい条件**（gap >= 10pt）は current_odds ベースの判断を信頼しない
3. **switch候補（1-3-2）の採用判断**も実払戻ベースで行う
4. **paper-forward 観察**では 実際の払戻金を記録し、current_odds との差を継続追跡する
